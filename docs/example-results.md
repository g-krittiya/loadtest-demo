# 📊 Metrics Meaning (with Example)

## 📌 Example Result

* Samples: **1150**
* Average: **1240 ms**
* Min: **988 ms**
* Max: **19908 ms**
* Std Dev: **928 ms**
* Throughput: **9.7 req/sec**
* Error %: **0.09%**

---

## 🧠 Meaning

### 🔢 Samples (1150)

จำนวน request ทั้งหมด
👉 ระบบถูกเรียก 1150 ครั้ง

---

### ⏱️ Average (1240 ms)

เวลาเฉลี่ยในการตอบสนอง
👉 โดยรวม ~1.2 วินาที

---

### ⚡ Min (988 ms)

เร็วที่สุด
👉 best case

---

### 🐢 Max (19908 ms)

ช้าที่สุด
👉 บาง request ใช้เวลา ~20 วินาที ❗

---

### 📉 Std Dev (928 ms)

ความแกว่งของเวลา
👉 ระบบไม่เสถียร (เร็วไม่เท่ากัน)

---

### 🚀 Throughput (9.7 req/sec)

จำนวน request ต่อวินาที
👉 รองรับได้ ~10 request/sec

---

### ❌ Error % (0.09%)

เปอร์เซ็นต์ที่ fail
👉 มี error น้อยมาก (ดี)

---

## 🎓 Key Insight

> Average looks OK, but Max is very high → bad user experience for some users
